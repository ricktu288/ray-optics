Real-scene engine benchmark

This benchmarks every gallery scene, every module scene, and the spherical lens scene variants. A second 5× density + linear color case is added when a scene contains a Beam, Point Source, or Angle Source (including sources inside modules).

Runs are configuration-major: all legacy cases, all primitive CPU cases, then every scene under each WebGPU setting. Each measurement is the second full updateSimulation on the same scene and engine, after an untimed update has compiled and warmed it. Timings include preprocessing, tracing, every rendering pass, Canvas 2D synchronization, WebGL finish(), and WebGPU queue completion.

Defaults use one measured sample and a 28-minute deadline. Query parameters: scene=id,id, group=gallery,module,sphericalLens, setting=legacy,primitiveCpu,webgpu-production,..., repeats=1, timeoutSeconds=30, deadlineMinutes=28, and autorun=1.
