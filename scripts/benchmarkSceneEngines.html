Real-scene engine benchmark

This benchmarks every gallery scene and every module scene. A second 5× density + linear color case is added when a scene contains a Beam, Point Source, or Angle Source (including sources inside modules). Default-color cases explicitly use a 0.01 ray-power cutoff for identical CPU and WebGPU workloads.

Runs are configuration-major: all primitive CPU cases, then all production WebGPU cases. Each case has one untimed update followed by consecutive measured updateSimulation calls on the same simulator, with no re-warmup between samples. Timings include preprocessing, tracing, every rendering pass, Canvas 2D synchronization, WebGL finish(), and WebGPU queue completion.

The default uses three measured samples and runs until every case finishes. Five production WebGPU calibration cases are selected from static expanded- primitive features to target the fitted coefficients and run first within the WebGPU pass. The resulting outgoing-ray and color-mode-specific render corrections are fitted only on those cases, then evaluated on the remaining cases. Query parameters: scene=id,id, group=gallery,module, setting=primitiveCpu,webgpu-production,webgpu-no-cooperation, repeats=3, calibrationCases=5, timeoutSeconds=30, and autorun=1.
